# CryptoChat 0.3.1a (C#) — база знаний в publish обновляется сама

Основа — 0.3.0a. Ответы бота и база знаний не менялись.

## Зачем

После правки вопросов в папке проекта `content\` приходилось вручную копировать её в `publish\content`
или пересобирать `CryptoChat.exe`. Теперь `publish\CryptoChat.exe` делает это сам при каждом запуске.

## Как работает

1. `build_exe.ps1` записывает в `publish\content-source.txt` полный путь к папке проекта `content`.
2. При запуске `CryptoChat.exe` сравнивает `publish\content` с папкой проекта (новые, изменённые и удалённые файлы).
3. Если есть отличия — сначала проверяет базу проекта так же, как при запуске бота (`config.json`, вопросы, синонимы).
4. База без ошибок копируется: во временную папку, затем подменяет `publish\content` — `publish\content` становится
   точной копией базы проекта. Сообщение: «База знаний обновлена из … (изменено файлов: N)».
5. База с ошибкой **не копируется**: бот пишет, в каком файле ошибка, и работает на прежней базе.

Ничего не происходит, если:
- папки проекта нет (например, `publish` скопирован на другой компьютер);
- `content-source.txt` нет (программа из установщика, старая сборка) — включается пересборкой `build_exe.ps1`;
- программа запущена с `--content <папка>` или с переменной `CRYPTOCHAT_CONTENT` — тогда база и так берётся оттуда.

Отключить: удалить `publish\content-source.txt`.

## Проверка

- 6 новых тестов (`ContentSyncTests.cs`): без изменений — ничего; изменённый, новый и удалённый файлы зеркалируются;
  база с ошибкой не копируется; нет папки проекта — молча; нет файла-указателя — ничего; указатель на свою же папку.
  Всего 255 тестов, все проходят.
- Вживую на собранной программе (Linux): правка в проекте подтягивается при запуске, сломанный `synonyms.json`
  не копируется (бот на прежней базе), без папки проекта бот работает как обычно.
