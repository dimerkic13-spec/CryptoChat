# CryptoChat 0.3.0a (C#) — установщик с поиском по смыслу

Основа — 0.2.9a. Ответы бота и база знаний не менялись.

## Зачем

Раньше, чтобы на новом компьютере заработал поиск по смыслу, нужны были .NET SDK, Python, PyTorch
и выгрузка модели (11 шагов, [SEMANTIC_SETUP.md](SEMANTIC_SETUP.md)). Теперь достаточно одного файла
`CryptoChat-Setup-0.3.0a.exe`: после установки бот сразу работает с поиском по смыслу, без интернета.

PyTorch и Python в установщик не входят и не нужны: они служат только для однократного перевода модели
в формат ONNX, а модель в C# считает ONNX Runtime, встроенный в `CryptoChat.exe`. Результат тот же,
что у Python-версии (`--check-model`: похожесть 1,000000).

## Что добавлено

| Что | Как |
|---|---|
| Установщик | `installer/CryptoChat.iss` (Inno Setup 6): `CryptoChat.exe`, `content`, `dicts`, `models` — и ничего лишнего; ярлыки в меню «Пуск» (бот, статистика, папка журналов, удаление) и на рабочем столе; удаление через «Параметры → Приложения» |
| Для кого ставится | по умолчанию — для текущего пользователя, без прав администратора (`%LocalAppData%\Programs\CryptoChat`); по выбору — для всех (`Program Files`) |
| Обновление | поверх старой версии; прошлые база знаний, словари и модель удаляются перед копированием новых — лишние файлы не остаются |
| Сборка | `build_installer.ps1`: проверка модели → поиск Inno Setup → тесты и сборка (`build_exe.ps1`) → `--check-model` в собранной программе → `dist\CryptoChat-Setup-<версия>.exe` |
| Папка данных | журналы бесед, база бесед, отзывы, выгрузки CSV и `secrets.json` — в `%LocalAppData%\CryptoChat` (а не рядом с программой): туда можно писать после установки, и данные не пропадают при пересборке, обновлении и удалении программы |
| Перенос старых журналов | при первом запуске журналы из папки `logs` рядом с программой (до 0.3.0a; при `dotnet run` — `bin\Debug\net10.0\logs`) один раз копируются в новую папку; старые файлы остаются |
| Новый ключ | `--data-dir` — показать папку данных; другую папку можно задать переменной окружения `CRYPTOCHAT_DATA` |
| При запуске | бот пишет, куда сохраняются журналы бесед |

Инструкция по сборке и установке — [INSTALLER.md](INSTALLER.md).

## Проверка

- 6 новых тестов (`DataDirectoryTests.cs`): папка данных по умолчанию и из `CRYPTOCHAT_DATA`, полные пути из
  `config.json`, поиск `secrets.json`, однократный перенос старых журналов без затирания новых. Всего 249 тестов, все проходят.
- Вживую (Linux): беседа пишется в папку данных, старые журналы с пометками об отправке на почту переносятся,
  `--sessions` читает перенесённую базу.
- `build_installer.ps1`: синтаксис проверен PowerShell, проверены ветки «нет модели» и «нет Inno Setup».
- **Не проверено здесь:** сама сборка установщика и установка — нужны Windows и Inno Setup.
  Первый запуск `build_installer.ps1` нужно сделать на Windows; если будет ошибка — по выводу скрипта она исправляется.
