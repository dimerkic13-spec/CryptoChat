# CryptoChat 0.2.5a — помощник КриптоПро (C#)

Консольный бот первой линии: отвечает на типовые вопросы клиентов КриптоПро готовыми ответами
из базы знаний (папка `content`), к каждому ответу прикладывает ссылку на источник. Ответы выдаются
дословно из базы, без ИИ. Если бот не уверен, он предлагает 1–3 варианта или уточняет тему,
а после 4 шагов уточнения без ответа направляет в поддержку.

Это C#-версия. Параллельно развивается Python-версия в репозитории
[CryptoChat_py](https://github.com/dimerkic13-spec/CryptoChat_py). Версия 0.2.5a повторяет
Python 0.2.5a: та же база знаний, тот же алгоритм. На 1558 проверочных диалогах ответы обеих версий
совпадают посимвольно (и со стеммером, и с морфологией).

## Что умеет

| Возможность | Как сделано в C# |
|---|---|
| Морфология: «рутокена» → «рутокен» | словари pymorphy3 (папка `dicts`), разбор перенесён из pymorphy3 — начальные формы совпадают с Python |
| Учёт опечаток: «рутокин» ≈ «рутокен» | своя функция похожести, считает так же, как RapidFuzz |
| Журнал каждой беседы | `logs/sessions/<номер сессии>.txt` |
| База бесед и статистика | SQLite `logs/cryptochat.db` (библиотека Microsoft.Data.Sqlite), отчёт `--stats` |
| Отправка журнала на почту | SMTP (библиотека MailKit), пароль в `secrets.json` или переменной окружения |
| Похожие вопросы до меню тем | «Точного совпадения не нашёл. Возможно, вы имели в виду…» |

Базы бесед обеих версий одного формата: `--stats` Python-версии читает базу C#-версии и наоборот.

## Требования

- .NET SDK 10 (https://dotnet.microsoft.com/download). Проверка: `dotnet --version`.
- Для готового `CryptoChat.exe` ничего ставить не нужно: .NET упакован внутрь.

## Запуск из исходников

```powershell
dotnet run --project src/CryptoChat.Cli
```

Ключи пишутся после `--`, например:

```powershell
dotnet run --project src/CryptoChat.Cli -- --selftest
```

| Ключ | Что делает |
|---|---|
| `--content <путь>` | взять базу из другой папки |
| `--validate` | проверить базу и выйти |
| `--selftest` | прогнать контрольные запросы (`content/acceptance.json`) и заголовки вопросов |
| `--compare` | сравнить стеммер и морфологию на контрольных запросах |
| `--morphology <режим>` | `stemmer`, `pymorphy3` или `auto` вместо значения из config.json |
| `--debug` | показывать, как бот ищет ответ (то же, что `/отладка вкл`) |
| `--test-email` | отправить тестовое письмо по настройкам `email` |
| `--send-pending` | дослать на почту журналы, которые не ушли раньше |
| `--stats` | статистика по базе бесед: частые ответы, отзывы, неотвеченные запросы |
| `--version`, `--help` | версия и подсказка |

Команды в диалоге: `/помощь`, `/темы`, `/темы 1.2`, `/отладка вкл`, `/отладка выкл`, `/сессия`, `выход`.

## Морфология

Режим задаётся в `content/config.json`:

```json
"text": { "morphology": "auto" }
```

| Значение | Что делает |
|---|---|
| `auto` | морфология, если папка `dicts/pymorphy3-ru` на месте, иначе стеммер |
| `pymorphy3` | только морфология; без словарей бот не запустится и скажет, чего не хватает |
| `stemmer` | простой стеммер (отрезает окончания) |

Словари лежат в `dicts/pymorphy3-ru` (16 МБ, пакет pymorphy3-dicts-ru, лицензия MIT, данные OpenCorpora)
и при сборке копируются рядом с программой. Другой путь можно задать в переменной окружения `CRYPTOCHAT_DICTS`.

## Учёт опечаток

```json
"fuzzy": { "enabled": true, "threshold": 85, "minLength": 5, "weight": 0.8 }
```

Слово с опечаткой засчитывается, если похожесть не ниже `threshold` (из 100) и оба слова не короче
`minLength` букв. Такой ключ даёт `weight` от своего веса, чтобы точное совпадение было весомее.

## Журнал беседы и база бесед

У каждой беседы свой номер сессии (например, `20261028-084012-7f3a`), он печатается при запуске
и по команде `/сессия`. Реплики сразу пишутся в `logs/sessions/<номер>.txt` и в базу `logs/cryptochat.db`
(папка `logs` — рядом с программой). Выключить: `"sessions": {"enabled": false}`, `"database": {"enabled": false}`.

```powershell
dotnet run --project src/CryptoChat.Cli -- --stats
```

## Отправка журнала на почту

1. В `content/config.json` в разделе `email` поставьте `"enabled": true`, укажите `smtpHost`, `smtpPort`,
   `security` (`ssl` для порта 465, `starttls` для 587), `username`, `from` и `to`.
2. Пароль **не пишите в config.json** (он попадает в Git). Создайте рядом с программой файл `secrets.json`
   по образцу `secrets.example.json`: `{ "smtpPassword": "пароль-приложения" }`.
   Или задайте переменную окружения `CRYPTOCHAT_SMTP_PASSWORD`.
3. Для Яндекса, Mail.ru и Gmail нужен «пароль приложения», а не обычный пароль от ящика.
4. Проверьте: `CryptoChat.exe --test-email` — должно прийти тестовое письмо.

Журнал отправляется после закрытия программы. Если отправить не удалось, он уйдёт при следующем запуске.

## Тесты

```powershell
dotnet test
```

Должно быть `Passed!`. Тесты проверяют стеммер, морфологию на настоящих словарях, опечатки, проверку базы,
поиск, диалог, журнал беседы, базу бесед, отправку почты (на подставном и на локальном SMTP-сервере)
и все контрольные запросы.

## Сборка CryptoChat.exe

```powershell
powershell -ExecutionPolicy Bypass -File build_exe.ps1
```

Скрипт прогонит тесты, соберёт `CryptoChat.exe` и проверит его. В папке `publish` будут `CryptoChat.exe`,
`content` (база знаний) и `dicts` (словари морфологии). Передавайте папку `publish` целиком (например, в zip).
Вопросы можно править в `publish\content` без пересборки.

## Структура

```
src/CryptoChat.Core/        ядро: вся логика бота
  Text/                     нормализация, стоп-слова, стеммер, синонимы, опечатки (FuzzyMatcher)
  Text/Morphology/          словари pymorphy3 (DAWG) и морфологический разбор
  Knowledge/                чтение content/, проверка (V001–V016), база в памяти
  Retrieval/                оценка вопросов, область поиска, топ-5
  Dialog/                   политика диалога и состояние беседы
  ChatEngine.cs             Ask(текст) → ChatReply, сборка ответа, команды
src/CryptoChat.Cli/         консоль, ключи запуска, журнал беседы, база бесед, почта, самопроверка
tests/                      тесты (xUnit)
content/                    база знаний: config.json, taxonomy.json, synonyms.json, questions/*.json,
                            acceptance.json (контрольные запросы), paraphrases.json (перефразы)
dicts/pymorphy3-ru/         словари морфологии
build_exe.ps1               сборка CryptoChat.exe
secrets.example.json        образец файла с паролем почты (сам secrets.json в Git не попадает)
```

## Как править базу

1. Правьте файлы в `content\` (вопросы — `questions\*.json`, синонимы — `synonyms.json`, пороги — `config.json`).
   База знаний общая с Python-версией: правки удобно переносить между репозиториями копированием папки `content`.
2. `--validate` — проверка формата.
3. `--debug` — посмотреть оценки по проблемному запросу.
4. `--selftest` — убедиться, что ничего не сломалось.
5. Добавить исправленный запрос в `content\acceptance.json`, сохранить в Git.

## Как добавить продукт (например, CSP)

1. В `content/taxonomy.json` под темой «Технические вопросы» добавить узел `"kind": "product"` с ключевыми словами продукта.
2. Создать файл `content/questions/2_1_csp.json` с вопросами (id начинается с номера узла, например `2.1.1.1`).
3. Добавить в `content/acceptance.json` несколько проверочных вопросов.
4. Выполнить `--validate` и `--selftest`, затем `dotnet test`.
