# Установщик CryptoChat-Setup.exe

Один файл, после установки которого бот работает сразу, **вместе с поиском по смыслу**.
На компьютере, куда ставят бота, ничего больше не нужно: ни .NET, ни Python, ни PyTorch, ни интернет.

Что ставится (только нужное для работы, около 230 МБ):

| Что | Зачем |
|---|---|
| `CryptoChat.exe` | бот; .NET и ONNX Runtime (запуск модели) — внутри |
| `content\` | база знаний: вопросы, ответы, настройки |
| `dicts\` | словари морфологии |
| `models\` | модель для поиска по смыслу (rubert-tiny2 в формате ONNX) |

Не ставятся: исходники, тесты, Python, `.venv`, PyTorch, кэш скачивания модели.

---

## Часть 1. Собрать установщик (один раз, на своём компьютере)

Нужны: папка бота, скачанная с GitHub, .NET SDK 10 и выгруженная модель в папке `models`
(как получить — [SEMANTIC_SETUP.md](SEMANTIC_SETUP.md), шаги 1–8; если поиск по смыслу уже работает
через `dotnet run`, модель у вас есть). Python для сборки установщика **не нужен**.

Команды — в PowerShell, по одной, в папке бота (например, `C:\Users\<имя>\Documents\CryptoChat\CryptoChat-0.3.0a`).

### Шаг 1. Установить Inno Setup 6 (один раз)

Бесплатная программа, которая собирает установщик. Нужна только на компьютере, где собирают, — у клиента не нужна.

```powershell
winget install --id JRSoftware.InnoSetup -e
```

Если `winget` не найден — скачайте Inno Setup 6 с https://jrsoftware.org/isdl.php и установите.
После установки **закройте PowerShell и откройте заново**.

### Шаг 2. Проверить, что модель на месте

```powershell
Test-Path ".\models\onnx\cointegrated--rubert-tiny2\model.onnx"
```

Должно быть `True`. Если `False` — скопируйте папку `models` из прошлой версии бота
(например, из `CryptoChat-0.2.9a\models`) в папку этой версии или выгрузите модель по SEMANTIC_SETUP.md.

### Шаг 3. Собрать установщик

```powershell
powershell -ExecutionPolicy Bypass -File build_installer.ps1
```

Скрипт по шагам: проверит модель, найдёт Inno Setup, прогонит тесты, соберёт `CryptoChat.exe`,
проверит базу знаний и модель в собранной программе, соберёт установщик. Занимает несколько минут.

В конце должно быть:

```
Готово: …\dist\CryptoChat-Setup-0.3.0a.exe (… МБ)
```

Этот файл и передавайте для установки (флешка, сетевая папка, почта, если пропустит по размеру).

## Часть 2. Установить бота (на любом компьютере с Windows 10/11, 64 бит)

1. Запустите `CryptoChat-Setup-0.3.0a.exe`.
   - Если Windows покажет «Система Windows защитила ваш компьютер» — нажмите **Подробнее → Выполнить в любом случае**
     (установщик не подписан цифровой подписью).
2. В начале установщик спросит, для кого ставить:
   - **«только для меня»** — права администратора не нужны, программа ставится в
     `C:\Users\<имя>\AppData\Local\Programs\CryptoChat` (рекомендуется);
   - **«для всех пользователей»** — нужны права администратора, программа ставится в `C:\Program Files\CryptoChat`.
     Журналы при этом всё равно у каждого пользователя свои (`%LocalAppData%\CryptoChat`).
3. Отметьте «Создать значок на Рабочем столе», если нужно, → **Установить** → **Завершить**.

После установки в меню «Пуск» → **CryptoChat**:

| Ярлык | Что делает |
|---|---|
| CryptoChat | запускает бота |
| Статистика CryptoChat | открывает окно с отчётом `--stats` |
| Журналы CryptoChat | открывает папку с журналами бесед и базой статистики |
| Удалить CryptoChat | удаляет программу |

При запуске бот пишет «Загружаю модель для поиска по смыслу…» — значит, поиск по смыслу работает.

### Где что лежит после установки

| Что | Где |
|---|---|
| Программа, база знаний, модель | `%LocalAppData%\Programs\CryptoChat` |
| Журналы бесед, база статистики, выгрузки CSV | `%LocalAppData%\CryptoChat\logs` |
| `secrets.json` (пароль почты, если нужна отправка журналов) | `%LocalAppData%\CryptoChat\secrets.json` |

Команды из PowerShell (статистика, проверка модели и т. п.) запускаются так:

```powershell
& "$env:LOCALAPPDATA\Programs\CryptoChat\CryptoChat.exe" --stats
```

```powershell
& "$env:LOCALAPPDATA\Programs\CryptoChat\CryptoChat.exe" --check-model
```

### Обновление

Соберите установщик новой версии и запустите его поверх старой. Программа, база знаний и модель заменятся
полностью (лишние файлы прошлой версии удаляются), **журналы и статистика сохранятся**.

Если вы правили базу знаний прямо в папке установки (`content`), при обновлении эти правки заменятся базой
из новой версии. Правьте базу в папке проекта (`content\`) и собирайте новый установщик.

### Удаление

«Параметры → Приложения → CryptoChat → Удалить» (или ярлык «Удалить CryptoChat»).
Журналы и статистика в `%LocalAppData%\CryptoChat` **не удаляются**, чтобы их не потерять.
Если они не нужны — удалите эту папку вручную.

## Если что-то пошло не так

| Сообщение | Что делать |
|---|---|
| `Нет модели (models\onnx\…\model.onnx)` | шаг 2 части 1 |
| `Не найден Inno Setup 6 (ISCC.exe)` | шаг 1 части 1; после установки откройте PowerShell заново. Или укажите путь: `build_installer.ps1 -InnoSetup "C:\Program Files (x86)\Inno Setup 6\ISCC.exe"` |
| `Тесты не прошли. Сборка остановлена.` | запустите `dotnet test` и пришлите вывод |
| `Модель в собранной программе не прошла проверку` | модель повреждена: удалите папку `models` и выгрузите заново (SEMANTIC_SETUP.md, шаг 7) |
| `Inno Setup завершился с ошибкой` | пришлите вывод скрипта целиком |
| После установки «Поиск по смыслу недоступен» | установщик собран без модели — проверьте шаг 2 части 1 и соберите заново |
