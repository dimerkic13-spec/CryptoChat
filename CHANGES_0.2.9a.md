и в командах статистики. Схема базы бесед `logs/cryptochat.db` не менялась: она по-прежнему общая

## Что добавлено

### Итог беседы в журнале

В конце `logs/sessions/<номер>.txt`, перед строкой «=== Конец сессии»:

```
Итог беседы:
  вопросов: 3, ответов: 2 (сразу: 1, после выбора из меню: 1), не ответил сразу: 1
  отзывы: помогло 1, не помогло 1
  выданные ответы:
    1.2.2.4   Хочу оплатить выставленный счёт на ИП с банковской карты. Такое возмож…
    1.2.1.1   Как получить счёт на покупку лицензий?
```

Вопросом считается сообщение пользователя, кроме номера пункта меню, команды (`/темы`) и «да»/«нет» в ответ
на «Ответ помог?».

### Анализ вопросов и статистика: `--stats`

| Раздел отчёта | Что показывает |
|---|---|
| Итоги | бесед, вопросов, ответов (сразу / после выбора из меню), без ответа, доля «помогло», в среднем за беседу, средняя длительность |
| Самые популярные вопросы | топ по числу выданных ответов: сколько сразу, сколько из меню, отзывы |
| Наименее популярные вопросы | вопросы, которые задавали, но реже всего |
| Ни разу не выдавались | вопросы базы знаний без единого ответа — возможно, клиенты ищут их другими словами |
| По разделам | сколько ответов пришлось на каждый раздел базы (доля от всех ответов) |
| Ответы с отзывом «не помогло» | с примерами запросов |
| Без ответа | запросы, на которые бот не ответил сразу (одинаковые складываются без учёта регистра) |
| По дням | бесед, вопросов, ответов, без ответа — за последние 14 дней периода |

Новые ключи:

| Ключ | Что делает |
|---|---|
| `--from <дата>`, `--to <дата>` | период (даты включительно), формат `2026-10-29` или `29.10.2026` |
| `--top <N>` | размер топов (по умолчанию 10) |
| `--stats-csv [папка]` | выгрузить в CSV для Excel: `questions.csv`, `sessions.csv`, `unanswered.csv`, `days.csv` (разделитель `;`, UTF-8 с BOM) |
| `--sessions` | список последних бесед: вопросов, ответов, без ответа, отзывы |
| `--session <номер>` | итог и вся переписка одной беседы |

## Python-версия

В Python-версии этих команд пока нет; её база бесед того же формата, поэтому её можно анализировать
командами C#-версии. Перенос в Python — отдельным шагом.
